# UsageRail agent skills

Skills that help coding agents add [UsageRail](https://usagerail.com) to an API server.

| Skill | What it does |
|---|---|
| [add-usagerail](skills/add-usagerail/SKILL.md) | Adds API keys, per-customer rate limits, quotas and usage metering to a Node.js or Python API |

The SDK source is at [usagerail/sdk](https://github.com/usagerail/sdk). Docs are at [usagerail.com/docs](https://usagerail.com/docs).
